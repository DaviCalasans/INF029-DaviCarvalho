### Passos para compilação e execução

1. Clone este repositório para a sua máquina:

2. Navegue até a pasta do projeto:
```bash
cd INF029-DaviCarvalho
```

3. Compile o projeto agrupando todos os arquivos .c:
```bash
gcc main.c aluno.c professor.c disciplina.c -o projetoEscola
```

4. Execute o programa compilado
No Windows:
```bash
.\projetoEscola
```
No Mac/Linux:
```bash
./projetoEscola
```
